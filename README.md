# Meesum Khan — Portfolio

Personal portfolio site, hosted for free on GitHub Pages.

## Local preview

Just open `index.html` in a browser, or serve it locally:

```
python -m http.server 8000
```

Then visit http://localhost:8000

## Deployment

This site is deployed via GitHub Pages from the `main` branch. After pushing,
enable it under repo Settings → Pages → Source: `main` branch, `/ (root)`.
